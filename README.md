# DSA OS – LeetCode Coding Practice Platform

A static, browser-based coding practice platform designed for DSA learning, coding interviews, and software engineering placements.

**Live Demo:** [DSA OS](https://mohdshamii.github.io/DSAos/)

## Features

- 250 curated LeetCode MNC placement problems across 17 topics.
- Monaco Editor with syntax highlighting.
- In-browser code execution for JavaScript and Python.
- C++ and Java execution using Judge0 CE API.
- Problem filtering by difficulty, topic, company, and status.
- Study roadmaps: Blind 75, Top Interview 150, and MNC 250.
- Progress dashboard, streak heatmap, and analytics.
- Custom study lists and daily coding goals.
- Local progress storage with JSON import/export.
- Responsive LeetCode-inspired dark interface.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Editor:** Monaco Editor
- **State Management:** Zustand
- **Routing:** React Router
- **Charts:** Recharts
- **Code Execution:** Web Workers, Pyodide, Judge0 CE
- **Storage:** LocalStorage, IndexedDB

## Run Locally

```bash
git clone https://github.com/mohdshamii/DSAos.git
cd DSAos
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

Deployed on GitHub Pages using GitHub Actions.
